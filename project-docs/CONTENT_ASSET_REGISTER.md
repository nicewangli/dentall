# 内容发布、商品批次、变更与素材登记（唯一活动登记簿）

本文件是DentAll当前唯一活动登记簿，用于记录内容发布/变更动作、商品CSV导入批次，以及设计稿、商品图、图标、字体、文案和许可证。占位素材在正式上线前必须替换或取得授权。

## 登记载体与维护规则

- 自2026-08-21起，所有新增内容发布、状态变化、审阅、撤回、恢复和素材授权记录只追加到本Markdown；D25起商品CSV导入批次也使用本文件的独立章节。不再生成、维护或要求使用Excel/Google表格。
- 早期生成的`DentAll-内容发布与素材授权登记.xlsx`所含D24 A/C3与A/C4共16条记录已完整迁移到本文件；该生成文件已于2026-08-22删除且不入库。A/C5及以后记录只以本文件为准。
- 每条内容动作使用三级标题和固定字段列表，保留对象、动作、状态、责任、证据、恢复方案与验证结果；没有可靠证据时明确写“未验证”或“待补”，不得根据`post_author`、修订版本或口头描述推断发布状态操作者。
- 日期时间以WordPress修订、后台截图、HTTP/REST证据或用户明确记录为准。A/C5历史补录仅登记日期`2026-08-21`，不虚构精确时间。
- 素材授权仍按资产ID单独治理。TEST图、占位图、来源不明或未获业务批准的素材不得登记为`批准公开`；内容事实确认与素材授权是两道独立闸门。

## 商品CSV批次登记

每次WooCommerce商品CSV导入新增一个三级标题，编号格式为`D25-CSV-YYYYMMDD-序号`，至少填写以下字段。原生商品作者和导入完成页只作辅助证据，不能替代本登记。

```markdown
### D25-CSV-YYYYMMDD-0001｜批次名称

- **环境与操作者：** Staging / Website Manager独立账号
- **日期时间：** WordPress显示时间及其时区
- **源CSV：** 文件名、SHA-256、行数；文件保存位置
- **导入模式：** 仅新增；`Update existing products`未勾选；普通/父商品`Published=-1`
- **涉及对象：** SKU清单或受控清单位置
- **导入前保护：** 商品导出文件名/指纹；应用文件＋数据库备份时间
- **原生结果：** Imported、Imported variations、Updated、Skipped、Failed；第一轮`Updated`必须为0
- **抽查：** Draft状态、作者、SKU、价格、库存、父子关系、分类/属性、图片和匿名公开面
- **异常与恢复：** 停止原因、已采取动作、开发者升级或恢复依据
- **复核结论：** 通过 / 未通过 / 待处理；证据位置
```

商品CSV批次记录不等于完整后台活动日志。自动活动日志是待选型增强项；第一版不得仅凭`post_author`推断最后修改人，也不得仅凭导入结果页声称整批可一键回滚。
