# 需求变更登记

## 使用规则

- 所有新增、修改、删除需求先登记，再进入开发。
- 需求未明确验收标准或影响时，状态为`Needs clarification`。
- 影响数据库、URL、支付、权限、SEO、缓存或生产环境的变更必须包含回滚方案。
- 未经确认，不将新增需求免费吸收进原工期。

## 状态

`Inbox → Needs clarification → Ready → In progress → Review → Staging → Awaiting approval → Done`
