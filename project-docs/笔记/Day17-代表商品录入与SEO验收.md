## 可复用核心思想

- 跨平台不变量：样本覆盖与内容真实性是两个维度。TEST数据可以证明字段、权限和状态机可运行，但不能证明正式名称、价格、库存、授权或合规事实正确。
- 跨平台不变量：代表样本应优先覆盖会改变数据结构或交易状态的分支，例如父子库存、非法组合、缺货和媒体集合；不需要为了清单完整而伪造低可信场景。
- WooCommerce实现：Variable商品以父商品承载系列身份，以Variation承载具体可售组合；独立库存时父级不管理数量，每个合法Variation维护唯一SKU、价格和库存，未建立组合不应通过选择器伪装为可售。
- SEO治理：草稿预览、Staging禁止索引和Production可索引是三种不同证据环境。能在登录态看到正确Title或Description，不等于公开URL、Canonical、Sitemap和301已经通过。
- Shopify或其他平台也需要区分产品、变体、库存和搜索摘要，但变体组合限制、草稿预览、Canonical及停售状态的具体机制在本项目未实测，标记为待验证，不能假设与WooCommerce一一对应。
