## 可复用核心思想

- 跨平台不变量：库存只能有一个权威真相源。父级共享库存和子项独立库存都是有效模型，但不能在同一销售对象上同时生效，否则会产生重复限制或错误扣减。
- WooCommerce实现：Variable父商品可以保留系列SKU并汇总价格与可购买性；具体Variation负责独立SKU、价格和库存。物流字段为空可继承父值，明确填写则覆盖。
- 默认选项不是纯粹的便利设置。默认值会直接决定首屏价格、库存、图片和可购买状态，因此只能指向真实、合法且可售的组合；没有业务默认时应要求客户主动选择。
- 非法组合应从可购买集合中消失，而不是用虚假价格、零库存或通配Variation伪装。这样能同时降低数据维护、前台歧义和订单错误风险。
- Shopify或其他平台同样需要区分产品级信息、变体级可售对象和库存位置，但父子SKU、库存策略及缺货行为的具体实现必须按平台实测，不能把WooCommerce界面直接套用为行业标准。
