# 商品与内容数据字典

## 字段选择规则

1. WooCommerce原生字段能表达的，不增加ACF。
2. 用户需要筛选的规格，使用全局商品属性。
3. 影响价格、SKU或库存的选择，使用商品变体。
4. 只用于结构化展示且原生字段不足的内容，才使用ACF。
5. 普通介绍放详细描述；简要卖点放简短描述。

## 商品原生字段

| 字段 | 数据源 | 必填 | 用途/规则 |
|---|---|---:|---|
| 商品名称 | WooCommerce | 是 | 清晰且唯一，避免堆砌关键词 |
| Slug | WordPress | 是 | 小写英文、短横线；确认后避免随意修改 |
| SKU | WooCommerce | 是 | 全站唯一；变体SKU也必须唯一 |
| 商品类型 | WooCommerce | 是 | 第一版主要为简单商品和可变商品 |
| 常规价格 | WooCommerce | 是 | 使用商城基准货币 |
| 促销价格/日期 | WooCommerce | 否 | 使用原生促销字段，不写进描述 |
| 库存状态 | WooCommerce | 是 | 有货、缺货、可延期交货规则待确认 |
| 库存数量 | WooCommerce | 视业务 | 若启用库存管理则必填 |
| 分类 | Product Category | 是 | 至少一个主分类，控制层级深度 |
| 标签 | Product Tag | 否 | 只用于明确运营需求，避免无限增长 |
| 品牌 | 待确认方案 | 建议 | W8前冻结实现方案和URL |
| 简短描述 | WooCommerce | 是 | 详情首屏卖点，建议80～200字 |
| 详细描述 | WooCommerce | 是 | 介绍、优势、使用范围和注意事项 |
| 主图 | Featured Image | 是 | 1:1，背景和安全边距统一 |
| 图库 | Product Gallery | 建议 | 细节、尺寸、应用场景；禁止重复图 |
| 重量/尺寸 | Shipping | 视物流 | 运费计算使用时必须准确 |
| 关联商品 | WooCommerce | 否 | 交叉销售、追加销售按业务配置 |

## 建议全局属性候选

以下只是候选，编辑录入代表商品后再冻结，禁止一次性创建大量无用属性。

| 属性 | 是否筛选 | 是否可能做变体 | 示例 |
|---|---:|---:|---|
| 材质 | 是 | 否/待确认 | Zirconia、PMMA |
| 规格/尺寸 | 是 | 是 | 98mm、不同包装规格 |
| 颜色/色号 | 视商品 | 是 | 不同shade |
| 适用设备/系统 | 是 | 否 | CAD/CAM系统 |
| 产品用途 | 是 | 否 | 临时修复、种植、正畸 |
| 包装数量 | 是 | 是 | 5pcs、20pcs、200pcs |
| 认证 | 视需求 | 否 | CE等，具体信息可配合ACF展示 |

## ACF最小候选字段

| 字段 | 类型 | 用途 | 是否进入第一版 |
|---|---|---|---|
| 技术参数组 | Repeater/Group | 有结构地展示参数名和值 | 待代表商品验证 |
| 认证信息 | Text/Repeater | 展示认证名称和编号 | 待确认 |
| 资料下载 | File/Repeater | PDF说明书、证书或目录 | Should |
| 使用说明 | WYSIWYG | 原生描述不便拆分时使用 | 待确认 |
| 交付周期 | Text | 定制类商品说明 | 待确认 |
| 商品FAQ | Repeater | 商品特有问答 | Could |

## 变体规则

- 只有会改变价格、SKU、库存、图片或购买选择的属性才设为变体。
- 控制变体组合数量；组合过多时重新评估商品拆分方式。
- 每个可售变体必须检查价格、库存状态、SKU和默认选择。
- 不可购买组合必须有清晰提示，不能静默失败。

## 内容类型

| 内容 | 推荐结构 | 说明 |
|---|---|---|
| 商品 | WooCommerce Product | 不创建重复CPT |
| 商品分类 | Product Category | 可维护层级和描述 |
| 品牌 | 官方能力或成熟插件 | 方案确认前不自建CPT |
| 博客 | WordPress Post | 使用分类管理主题 |
| About/政策 | WordPress Page | 共用内容页模板 |
| Solutions | Page或CPT待定 | 数量少用Page；大量且需归档再用CPT |
| 案例 | 暂不进入第一版 | 需求明确后再决定CPT |

## 文章与页面字段

| 字段 | 内容类型 | 必填 | 规则 |
|---|---|---:|---|
| 标题 | Post/Page | 是 | 清晰描述主题，避免堆砌关键词 |
| Slug | Post/Page | 是 | 小写英文和短横线；发布后未经SEO确认不得修改 |
| 摘要 | Post | 是 | 用于文章列表和分享摘要，避免直接截断正文 |
| 正文 | Post/Page | 是 | 使用统一标题层级；不粘贴外部内联样式 |
| 特色图 | Post | 是 | 按约定比例上传，并填写可理解的alt |
| 分类 | Post | 是 | 至少一个主分类；D25后不随意新增近义分类 |
| 标签 | Post | 否 | 有明确聚合价值才使用，避免一文一标签 |
| 作者 | Post | 是 | 使用真实或统一品牌作者账号 |
| SEO标题/描述 | Post/Page | 建议 | 使用SEO插件字段；上线前抽样检查 |
| 内部链接 | Post/Page | 建议 | 链接相关商品、分类或内容，禁止使用临时Staging绝对地址 |
| 发布状态 | Post/Page | 是 | 试录阶段保存草稿；按审核规则发布 |

## 编辑录入验收

- 第一批只录入5～10个代表商品，覆盖简单商品、变体、促销、缺货、多图和资料下载。
- D18商品模型候选冻结前不要批量导入全部商品。
- D24前先录入3篇不同长度文章和1个固定页面，验证摘要、特色图、内链、SEO和发布流程。
- D25综合验收后才开放批量录入；此后未经确认不得改变核心商品字段、文章分类结构、Slug规则和固定链接。
- 每次字段改变记录迁移影响、旧数据处理和新增工时。
