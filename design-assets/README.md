# 设计素材目录规则

此目录用于后续整理效果图、可编辑源文件、导出图、图标、字体和授权记录。当前已有图片和`dentall-responsive-package`暂留`D:\new-project`，本次只迁移项目文档，不移动设计源文件。

建议后续分类：

```text
design-assets/
├─ references/     效果图和参考图
├─ sources/        可编辑源文件
├─ exports/        前端使用的优化导出资源
├─ fonts/          字体及许可证
└─ licenses/       来源、授权和购买凭证
```

## 规则

- 开发占位图和最终上线素材必须明确区分。
- 每个最终素材记录来源、作者、授权、使用页面和文件路径。
- 不把大型设计文件提交到普通源码Git；需要版本控制时使用独立仓库或Git LFS。
- 前端导出图使用可预测英文文件名，记录尺寸、比例和压缩方式。
